# 具身智能成果日报

在 Windows 本机每天北京时间 **09:00** 开始检索具身智能最新成果，生成中文日报，并通过桌面通知提醒阅读。

按研究重要程度选取 **最多 20 篇（项）**，不设最低数量。结合问题价值、方法创新、实验可信度、领域影响和复现价值排序，每项给出入选理由、原始来源和局限。

## 日报关注什么

- VLA、机器人基础模型、世界模型。
- 具身导航、移动操作。
- 人形机器人、运动控制、灵巧操作。
- 机器人数据集、评测基准、仿真到现实。

同时检索中英文来源，优先核对论文、研究机构及作者项目页和官方代码仓库。区分实机实验、仿真结果和公告信息；不将宣传或演示当作可靠评测。

首次运行回顾最近 7 天，之后以过去 24 小时的新增或实质更新为主。对检索延迟可补录最近 7 天的重要成果，并注明实际发布日期。按论文与项目去重，保留近 30 天已报道记录。

## 使用条件

- Windows，Python 3.10 或更高版本，`python` 已加入 PATH。仅使用 Python 标准库。
- 已安装 Codex 桌面应用，并完成 ChatGPT 登录。脚本会在 `%LOCALAPPDATA%\OpenAI\Codex\bin` 中查找应用附带的命令行程序；需要可用的联网搜索能力、模型权限及账户额度。
- 当前脚本使用 `gpt-6.1-sol`；如账户不支持该模型，请调整 `run_daily.py` 中的模型参数。
- 定时安装脚本使用 Windows 系统时间；请将 Windows 时区设为“中国标准时间（UTC+08:00）”，以对应北京时间 09:00。
- 执行时电脑需开机、联网，当前 Windows 账户保持登录。无需另外配置 API 密钥。

## 开始使用

1. 克隆本仓库，放到长期保留的文件夹。
2. 双击 `立即汇总.cmd`，确认能生成日报。
3. 在仓库目录运行以下命令安装每天的任务：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install_schedule.ps1
```

任务名为 `EmbodiedAI-Daily-0900`。09:00 是开始检索时间，完成后通知；生成时间随候选数量和网络情况变化。错过时间后补跑，执行失败每 15 分钟重试一次，最多重试 2 次。Windows 通知设置可能影响提醒显示。

安装后请保持仓库目录位置不变；移动目录时，应先在 Windows 任务计划程序删除旧任务，再从新位置安装。

## 阅读和管理

| 文件或目录 | 用途 |
| --- | --- |
| `最新日报.html` | 固定阅读入口，浏览器打开 |
| `日报/` | 按运行时间归档的 Markdown 和 HTML |
| `日志/` | 检索记录、结构化结果和失败原因 |
| `运行状态.json` | 最近运行状态 |
| `已报道.json` | 去重历史 |
| `立即汇总.cmd` | 手动重新生成今日汇总 |
| `暂停定时任务.cmd` | 暂停每天自动运行 |
| `恢复定时任务.cmd` | 恢复每天自动运行 |

运行产物、检索日志、账户文件和本机定时任务导出文件由 `.gitignore` 忽略。克隆仓库不会自动创建计划任务，也不会带入原机器的登录状态和日报历史。

## 调整筛选规则

- `workflow.md`：完整流程与交付约定。
- `prompt.md`：每次检索实际使用的指令，包括主题覆盖、时间核验和重要度筛选。
- `report.schema.json`：结构化输出格式，成果条目上限为 20。
- `run_daily.py`：执行、校验、归档和通知入口；程序也检查 20 条上限。
- `install_schedule.ps1`、`notify.ps1`：Windows 定时任务及桌面提醒。

修改流程和检索指令后，下次执行会自动读取最新文件。改变条目上限时，需要同时更新流程、指令、输出格式和程序校验。

## 证据与限制

日报是研究初筛材料，不能保证穷尽所有最新论文。检索失败和覆盖不足会单独标注；未经核对的实验数字不作为确定结论。重要论文仍建议人工选择、阅读原文和复现验证。

流程借鉴《AI 辅助科研保姆级教程｜选题到投稿全流程》（库森 @kusengo）中的检索核验、结构化阅读与分层总结思路。
