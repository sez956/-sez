# 具身智能成果日报

每天北京时间 **09:00** 自动汇总具身智能论文，每期最多 **20 篇**，不设最低数量。

现在提供两种模式，默认使用 **免模型版，不调用 GPT，不消耗 GPT/Codex 额度**。

| 模式 | 能做什么 | 环境 |
| --- | --- | --- |
| 免模型版（默认） | arXiv API/RSS 检索、日期过滤、去重、规则排序、作者原始摘要、论文链接 | 本机只需 Python 3.10+；也可在 GitHub 云端运行 |
| 模型版（可选） | 多源搜索、原文核验、中文综合分析和阅读建议 | Windows、Python、Codex 登录与可用额度 |

免模型版的规则分用于相关性和阅读线索筛选，**不等同于模型式的重要性判断或学术评审**。摘要保留原文，不自动翻译；作者声称的实验结果也不会被误标为已核验。

## 没有本地环境：直接在浏览器使用

打开 [Actions](https://github.com/sez956/-sez/actions) → **Free embodied AI digest** → **Run workflow**。完成后在该次运行的 Summary 阅读日报，或下载 Artifacts 中的 HTML/Markdown。

云端也配置了每天 `01:00 UTC`（北京时间 09:00）运行；GitHub 可能延迟或暂停长期不活动仓库的计划。云端无需本机开机、安装 Python、Codex 或配置模型密钥，使用的是 GitHub Actions 的运行和存储资源；是否计费取决于账户与仓库套餐。详细步骤见 [环境说明](ENVIRONMENT.md)。

## Windows 本机快速开始

1. 下载仓库并解压到固定目录。
2. 安装 Python 3.10+，双击 **安装环境.cmd**；已有 Python 时无需重复安装。脚本会创建本项目的独立环境并检查网络，无第三方 pip 依赖。
3. 双击 **立即汇总.cmd** 运行免模型版，打开 **最新日报.html** 阅读。
4. 双击 **安装定时任务.cmd**，每天北京时间 09:00 自动开始，完成后桌面提醒。

[完整环境说明与故障排查](ENVIRONMENT.md) 包含 Python 安装、换设备、macOS/Linux、代理设置以及云端使用方式。

## 筛选与覆盖

关注 VLA、机器人基础模型、世界模型、操作与灵巧手、具身导航、人形和运动控制，以及机器人数据集、评测与仿真到现实。

- 免模型版回看最近 7 天以补漏，按 arXiv ID 与摘要/备注变化去重，保留近 30 天历史。输出不超过 20 篇，达到阈值的候选不足时相应减少。
- 规则、权重和命中原因可检查，不按机构名气或营销热度加分。它可能漏掉缺乏常见关键词的重要论文，也可能选入价值一般的匹配论文。
- 默认仅覆盖配置中的 arXiv 论文和 RSS 备用源；源失败、分页上限和未知日期会如实标注，不宣称覆盖全部最新成果。
- 可选模型版按研究问题、创新、证据和复现价值综合筛选；流程与检索指令见 `workflow.md`、`prompt.md`。

## 常用文件

| 文件 | 用途 |
| --- | --- |
| `free_digest.py` | 跨平台免模型入口 |
| `config.free.json` | 20 篇上限、规则阈值、检索词和代理配置 |
| `outputs/free/latest.html` | 免模型日报，根目录也更新 `最新日报.html` |
| `outputs/free/status.json` | 免模型运行状态与错误原因 |
| `outputs/free/history.json` | 免模型已报道历史 |
| `bootstrap.ps1` / `check_environment.py` | 环境创建与检查 |
| `安装定时任务.cmd` | 安装/切换至免模型版定时任务 |
| `暂停定时任务.cmd` / `恢复定时任务.cmd` | 管理本机定时任务 |
| `模型版汇总.cmd` / `run_daily.py` | 手动运行消耗 Codex 额度的模型版 |
| `ENVIRONMENT.md` | 安装、迁移、网络与云端使用说明 |

运行产物、日志和本机环境默认不会提交到仓库。云端和各台本机的去重历史独立；迁移时重建 `.venv`，不要复制原设备的虚拟环境。论文筛选始终只是科研初筛，重要结论需要阅读原文与复现验证。

流程参考库森 @kusengo《AI 辅助科研保姆级教程｜选题到投稿全流程》中的检索核验、结构化阅读和分层总结思路。公开接口与安装资料链接见 [ENVIRONMENT.md](ENVIRONMENT.md)。
